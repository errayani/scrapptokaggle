# 📍 ScrapperNum - Google Places Lead Generation Tool

An advanced, web-based data extraction and lead generation tool built with Python and Streamlit. It fetches business information from the Google Places API, applies smart filtering, protects PII (Personally Identifiable Information), and provides dual-format exports tailored for marketing campaigns and Kaggle research.

---

## 🚀 Key Features

* **🔍 Google Places API Integration:** Search for businesses, clinics, or services by category and city/location with pagination support.
* **📱 WhatsApp Number Validation:** Filters and validates local phone numbers to detect WhatsApp readiness.
* **🛡️ PII Protection:** Built-in safeguards to clean and manage sensitive data securely.
* **📊 Dual Export Options:**
  * **Excel (.xlsx):** Formatted neatly for marketing and sales outreach teams.
  * **CSV:** Cleaned and structured for data analysis and Kaggle datasets.
* **🌐 Cross-Platform Access:** Easily deployable as a web app or installable as a Progressive Web App (PWA) on mobile and desktop.

---

## 🛠️ Technology Stack

* **Frontend & Backend:** Python, Streamlit
* **Data Processing:** Pandas, Openpyxl
* **API Requests:** Requests (Google Places API)
